# 🪔 Diya Chain

Light a diya, add a Diwali wish, and watch the mandala of lights grow as friends join, live.

**Live:** https://voideepak.github.io/diwali/

- Share the link, or tap **＋ Circle** to make a private chain for family or friends (`?c=<circle-id>`).
- Static site on GitHub Pages: no server, no accounts, no cost.
- Diyas are stored as small signed messages on free, open [Nostr](https://nostr.com) relays. Each browser gets its own key, kept in `localStorage`.
